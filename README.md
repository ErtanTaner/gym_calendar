# gym_calendar
AI assisted gym calendar which creates workout programs with user input. Uses Flask and Deepseek. 

## Example Prompt
"I weigh 90kg and I'm 1.70m tall. I want to focus on weight loss and have lower back issues. Create a program from 2025-10-12 to 2025-10-18."

## How to setup?
1. Add needed values to .env-example.
2. Install firebase cli for emulators.
3. Create a venv.
4. Run both emulators and flask.
